# Ревью доработки (rev B на PICO и вариант 1 Вт) — субагенты, второй круг

Три проверяющих: разводка rev B, схемы rev B/1 Вт по даташитам, производственные файлы rev B.

## Схемы по даташитам (PICO-D4, QPF4219, RFSW8009)

**rev B (PICO-D4):** все 49 выводов сверены с таблицей 2 даташита — совпадают. Референс-схема
Espressif (RC на EN, strapping-подтяжки IO0↑/IO2↓/IO12↓/IO15↑, развязка, VDD_SDIO) покрыта.
Согласование антенны уже внутри SiP, LNA_IN ≈ 50 Ом.

| Находка | Статус |
|---|---|
| J4 выв. 8/9 (IO16/IO17) у PICO заняты внутренней флешью — висели | **исправлено**: выводы гребёнки помечены NC |
| IO12/IO2/IO15 на гребёнке J4 — внешняя подтяжка при старте ломает загрузку | в доке, риск пользователя |

**1 Вт (QPF4219 + RFSW8009):** распиновка обоих чипов и таблицы истинности совпадают с даташитами.
PA_EN+C1=TX_EN, C0=RX_EN даёт ровно режимы Transmit / LNA On / All Off.

| Находка | Серьёзность | Статус |
|---|---|---|
| **PA без питания**: выводы VCC0/1/2/VDD в символе стояли вне сетки 1.27 мм, генератор ставил метки в 0.63 мм от вывода — цепь V_PA не доходила до U9 | критично | **исправлено**; `gen_sch.py` теперь отказывается генерировать при выводе вне сетки |
| Нет аттенюатора перед TX_IN: abs.max +12 дБм, для +28 дБм на выходе нужно ≈−5 дБм на входе, ESP32 даёт минимум +2 дБм | критично | **исправлено**: пи-пад 6 дБ (R22 39R, R23/R24 150R) |
| Развязка по EVB Qorvo: 0.1u+2.2u у каждой VCC0/1/2, 0.1u у VDD | важно | **исправлено** (C31–C37) |
| ВЧ-фильтрация линий управления (100p на PA_EN, 1n на VCONT) | мелочь | **исправлено** (C38, C39 1nF) |
| Выв. 8 и 20 «рекомендуется на землю» | мелочь | **исправлено** |
| Bypass-режим LNA недостижим (C1 привязан к PA_EN); вход LNA перегружается при +10 дБм на ANT | риск | в доке; при необходимости C1 на отдельный GPIO |

### Что понадобилось, чтобы дойти до DRC 0

Первые перетрассировки после правок давали 14–18 несоединённых цепей. Причины и решения
(всё — в генераторе, воспроизводимо):

| Проблема | Решение |
|---|---|
| Земляные площадки 0402/SOIC/QFN оставались островами: полигон F.Cu режется дорожками, а freerouting не сажает переходные на плоскости | **GND fanout**: у каждой земляной SMD-площадки своя переходная Ø0.5 со стабом 0.3 мм, ставится до трассировки (роутер обходит); земляные выводы U4 — стабами к теплоотводу |
| Земля в DSN «без имени» → freerouting молча вставал на диалоге (0 % CPU, 25 мин) | земля вынесена в класс `SKIP`, роутер запускается с `-inc RF,SKIP`; при импорте сессии земля из SES игнорируется (иначе дубли переходных) |
| Дорожка от выв. 5 (SENSOR_VP) вдоль торцов запирала выводы 8–12 | SENSOR_VP/VN не разводятся (NC на J3), C42 стоит прямо у торцов 3/4 |
| Кнопки SW1/SW2 и таб AMS1117: две площадки с одним номером — freerouting считает их одним выводом и не соединяет, KiCad требует медь | генератор ставит locked-перемычку между одноимёнными площадками |
| Верхний ряд: strapping-резисторы в 3 мм от выводов давали петли | резисторы у кромки (y=4.2), C43 (1 мкФ) над выв. 19 |
| Нижний ряд: дорожка 43→C40 запирала 38–42 | перемычка 43↔46 под торцами NC-выводов 44/45, C40 справа |
| Правый ряд: питание 3/4 с коленом перекрывало выв. 5 | стабы 3/4 прямо в pad1 C42 у торцов |
| Ручная дорожка C44 шла поверх его же земляной площадки (C44 был развёрнут не той стороной) | поворот 180° |

Итог: **DRC — 0 ошибок** (предупреждения только по шелкографии), ВЧ 0.38 мм над сплошной In1,
все земляные площадки с переходными. Рендеры: `docs/img/pcb_pico_top.png`, `docs/img/pcb_pico_all.png`.

## Производственные файлы rev B (третий круг — DFM-ревью финального пакета)

Ревьюер сверил герберы с платой (386 флэшей F.Cu = 195 SMD + 56 PTH + 135 via на тот момент,
ВЧ-цепь 0.38 мм от U1 до J5 прослеживается в гербере), комплект для 4 слоёв полный, BOM/CPL
46 = 46, все LCSC на месте и совпадают с требуемыми (U1 C193707, U4 C19213, U3 C84681,
U2 C6186, Q1/Q2 C2150, J1 C165948).

| Находка | Серьёзность | Статус |
|---|---|---|
| 9 переходных под EP U1 имели окна в маске снизу → припой утёк бы в отверстия, пустоты под EP; опция JLC «Via covering» на них не действует (в drl это площадки детали) | средняя | **исправлено**: слои только `*.Cu` (как у U4) |
| Паста на EP U4 76 % (4 квадрата 0.74 мм) | средняя | **исправлено**: ×0.81 → ≈50 % |
| Via Ø0.5/0.25: кольцо 0.125 мм ровно на минимуме JLC, требует явного выбора сверла 0.25 в заказе | средняя | **исправлено**: все переходные 0.6/0.3, плата переразведена |
| Дорожка IO27 на In2 в 0.37 мм от края (JLC мин. 0.3, для внутреннего слоя лучше ≥0.5) | низкая | **исправлено**: зазор медь–край 0.5 мм в правилах, переразведено (ближайшая дорожка 0.97 мм) |
| Hole-to-hole 0.25 мм в сетке EP U4 (одна цепь) | низкая | оставлено, DFM-пометка JLC штатная (в ordering.md) |
| Маска между выводами QFN 0.25 мм — для зелёной ок, для других цветов JLC может снять перемычки | низкая | заказывать зелёную |
| Паста на площадках J5 (SMA) — трафарет напечатает пасту без детали | косметика | оставлено |
| H4 не в линии с H3 | косметика | **исправлено** (52, 48) |
| ordering.md: не сказано про EP-площадки и Via covering; текст шелка для шага 1 от rev A | низкая | **исправлено** |

**Повороты в CPL** (сырые углы KiCad; JLC ориентирует по ленте — типичные поправки для
KiCad-футпринтов: SOT-23/SOT-223 +180°, SOIC/QFN +270°, USB-C +180°). Сверять в превью:
U1 (180°) — выв. 1 в правом нижнем углу, выв. 2 (LNA_IN) над ним, смотрит вправо;
U4 выв. 1 слева-сверху; U3 выв. 1 слева-сверху; U2 таб (VOUT) справа; Q1/Q2 коллектор справа;
J1 разъём вниз к краю; D1 катод слева (на +5V); D2 катод вниз; D3 катод вправо.

**Extended-детали** (≈3 $/фидер): C193707, C19213, вероятно C327292 (1.2 пФ) и C269824 (3 нГ) —
итого ~9–12 $. Наличие на складе и статус basic/extended смотреть живьём при заказе.

Отказа DFM не ожидается.
