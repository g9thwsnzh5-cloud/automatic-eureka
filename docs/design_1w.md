# Вариант на 1 Вт (QPF4219) — rev A

Это переделка платы под полную мощность, как в оригинале ESP32-M1 Reach Out.
Схема ВЧ-части воспроизводит открытый (GPL) проект Reach Out, но только Wi-Fi.
Генерируется из `hardware/kicad/tools/design_1w.py`.

## Статус: электрика подтверждена по даташитам, футпринты построены

По присланным даташитам Qorvo распиновка и таблица управления **QPF4219** и
**RFSW8009** подтверждены поштучно, футпринты построены из даташитов. Осталось
доуточнить перед заказом:

| Деталь | Статус | Доуточнить перед оплатой |
|---|---|---|
| QPF4219 | QFN-24 **3×5**, распиновка и шаг 0.5 мм из даташита; периметр площадок по land pattern 4.84×2.84 REF | Размер EP и смещение угловых площадок — сверить с чертежом стр.7 или подтянуть футпринт из EasyEDA (**C471154**) |
| RFSW8009 | распиновка по даташиту Rev E (RFC=выв.5), 6-pad 1.86×1.5; футпринт приближён | Складской номер на LCSC, сверить землю/EP |
| FIL1 (LTCC BPF 2.45) | 0603 | Выбрать BPF (Johanson 2450BP / TDK DEA), взять номер |
| L2 4.3нГ, C25/C26 1.8пФ | пи-фильтр (ретюн под 2-ю гармонику) | Подобрать ВЧ-номера на LCSC |

**Исправление по даташиту:** сначала общий порт переключателя RFC стоял на выводе 1 —
на самом деле он на **выводе 5**. Исправлено: RFC=SW_COM=выв.5, RF1=TX=выв.1,
RF2=RX=выв.3, VCONT1=TX_EN=выв.6, VCONT2=RX_EN=выв.4.

Самый надёжный путь по футпринтам: подтянуть QPF4219 из EasyEDA (C471154), чтобы
получить точный EP и угловые площадки. Построенные здесь футпринты пригодны для
разводки, но EP/угловые площадки — под проверку.

## ⚠️ Законность

1 Вт (30 дБм) на 2.4 ГГц в Израиле и ЕС вне закона: лимит около 100 мВт ЭИИМ.
Плата легальна только в лаборатории/по лицензии, а в быту мощность обязательно
крутить вниз прошивкой. Прошивка `firmware/` по умолчанию держит ESP32 на низкой
мощности; для 1 Вт это надо сознательно поднять.

## Чем отличается от rev A (100 мВт)

| | rev A (100 мВт) | 1 Вт |
|---|---|---|
| Усилитель | RFX2401C (PA+LNA+switch в одном), 3.3 В | QPF4219 (PA+LNA+SP2T), 5 В |
| Выход PA | ~+20 дБм | ~+30 дБм (1 Вт) |
| Переключатель ESP32↔PA/LNA | внутри RFX2401C | внешний RFSW8009 (ESP32 имеет одну ВЧ-ногу) |
| Питание усилителя | +3V3 через феррит | +5 В (USB) через феррит, net V_PA |
| Управление | TXEN, RXEN | PA_EN+C1(TX), C0(RX) + управление переключателем — те же 2 GPIO |

«Передняя» часть (модуль ESP32-WROOM-32U, USB-C, CH340C, автосброс, питание 3.3 В)
взята из rev A без изменений — она проверена по библиотечным футпринтам.

## Распиновка QPF4219 (QFN-24, из GPL-схемы Reach Out, лист 2)

| Вывод | Имя | Цепь на плате |
|---|---|---|
| 2 | TX_IN | вход PA, от переключателя (TX_PATH) |
| 17 | ANT | общий ВЧ-порт → выходной фильтр → антенна |
| 15 | RX_OUT | выход внутреннего switch на приём → C23 → LNA_IN |
| 13 | LNA_IN | вход LNA |
| 12 | LNA_OUT | выход LNA → переключатель (RX_PATH) |
| 4, 19 | PA_EN, C1(TX) | связаны вместе → линия TX_EN (GPIO23) |
| 16 | C0(RX) | линия RX_EN (GPIO18) |
| 10, 22, 23, 24 | VDD_LNA, VCC2, VCC1, VCC0 | питание +5 В (V_PA) |
| 1,3,7,9,11,14,18,21,25(EP) | GND | земля |
| 5, 6, 8, 20 | NC | не подключены (6 = DC_PDET, не используется) |

**Таблица управления** (из схемы Reach Out):
- Передача: PA_EN=1, C1=1, C0=0  → GPIO23 высокий, GPIO18 низкий
- Приём: PA_EN=0, C1=0, C0=1  → GPIO23 низкий, GPIO18 высокий
- Выкл: всё низкое  → оба GPIO низкие

То есть та же прошивка (`fem_rfx2401`), GPIO23→TX_EN, GPIO18→RX_EN. Дополнительно
эти же две линии управляют переключателем RFSW8009 (V1=TX_EN, V2=RX_EN). Подтяжки
R20/R21 10к вниз держат усилитель выключенным до инициализации.

## ВЧ-цепь по порядку

```
ESP32 U.FL → J2 → C20 → RFSW8009(U10) ─TX_PATH→ C21 → PA_IN(2) ─PA→ ANT(17)
                          │                                          │
                          └RX_PATH← C22 ← LNA_OUT(12) ←LNA← LNA_IN(13)← C23 ← RX_OUT(15)←switch←ANT
ANT(17) → C24 → FIL1 (LTCC BPF 2.45) → L2 4.3нГ / C25,C26 1.8пФ (пи, ретюн) → J5 SMA
```

Номиналы пи-фильтра подобраны по замечанию ВЧ-ревью: срез около 3.5 ГГц, чтобы
реально давить 2-ю гармонику 4.9 ГГц (в rev A было 3нГ/1.2пФ со срезом ~5.3 ГГц,
что гармонику не снимало). Проверять на анализаторе спектра.

## Питание PA

VCC берётся от USB 5 В (net V_PA) через ферритовую бусину FB2 и развязку
22мкФ/1мкФ/100нФ/10пФ. QPF4219 хочет ≥4.75 В; USB даёт ~5 В (перед диодом D1).
На 1 Вт пик тока PA — сотни мА, поэтому питание берём от VBUS напрямую, а не от
3.3-вольтового стабилизатора. Для чистого питания в следующей ревизии — отдельный
LDO 5 В (в оригинале TPS7A5201), это улучшит PSRR и стабильность усиления.
